# Digest tech - 2026-08-09

_Hoy domina: OpenAI compra NextSlide, DeepMind avanza en meteorología con IA y Amazon enfrenta críticas por emisiones de centros de datos._

**OpenAI adquiere la startup NextSlide**

OpenAI compró la startup de presentaciones NextSlide, cuyos integrantes ya se encuentran trabajando en ChatGPT. Esta adquisición busca potenciar las capacidades de la plataforma de IA.

https://techcrunch.com/2026/08/08/openai-acquires-presentation-startup-nextslide/

**Modelo WeatherNext de DeepMind predice huracanes**

El modelo de código abierto WeatherNext de DeepMind logró realizar predicciones precisas de ciclones utilizando datos meteorológicos de menor resolución. Esto demuestra avances significativos en la aplicación de IA para la ciencia climática.

https://arstechnica.com/science/2026/08/deepminds-hurricane-model-bought-forecasters-an-extra-day/

**Centro de datos de Amazon y su impacto ambiental**

Amazon está invirtiendo en una central eléctrica de gas en Texas para abastecer un centro de datos proyectado, la cual podría convertirse en la mayor fuente de contaminación climática en Estados Unidos. El proyecto ha generado fuertes cuestionamientos ambientales.

https://techcrunch.com/2026/08/08/planned-amazon-data-center-could-become-the-biggest-climate-polluter-in-the-u-s/

**Shopify reemplaza Redis con MySQL para inventarios**

Shopify migró su sistema de reservas de inventario desde Redis hacia MySQL y logró mantener la escalabilidad con éxito. La decisión técnica optimiza la infraestructura de datos de la plataforma de comercio electrónico.

https://shopify.engineering/scaling-inventory-reservations
